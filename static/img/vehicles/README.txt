SLOT FOTO KENDARAAN ASLI (OPSIONAL)
===================================
Sistem HargaBekas secara otomatis memeriksa keberadaan file foto asli berformat .webp di folder ini
dengan pola penamaan huruf kecil (spasi diganti tanda hubung):

/static/img/vehicles/{merek}-{model}.webp

Contoh nama file yang didukung sesuai katalog:
- honda-vario-160.webp
- yamaha-nmax-155.webp
- honda-cbr150r.webp
- yamaha-mx-king-150.webp
- kawasaki-klx-150.webp
- honda-brio-rs.webp
- honda-civic-rs.webp
- toyota-avanza-veloz.webp
- toyota-fortuner-vrz.webp
- toyota-innova-zenix.webp

Jika file .webp tersebut tidak ditemukan, sistem secara otomatis menampilkan ilustrasi vektor
2D SVG presisi tinggi buatan HargaBekas yang mendukung perubahan warna bodi secara interaktif.
